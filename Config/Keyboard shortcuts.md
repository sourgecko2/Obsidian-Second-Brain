#### overall, just use cmd + p if shortcut unknown.
## Main / important
`cmd + p`  =  command palette
`cmd + e`  =  toggle reading mode
`cmd + o`  =  quick switcher
`cmd + shift + f`  =  search all files
`cmd + n`  =  new note (QuickAdd "New Note" template)
`cmd + shift + n`  =  open QuickAdd choice picker
`cmd + shift + a`  =  open Copilot chat
`cmd + option + ←/→`  =  navigate back/forward (like a browser)
`cmd + shift + k`  = quickly capture text to the [[Captures]] file
`cmd + shift + b`  = bookmark
`shift + click` on checkboxes for a 'kinda' done.
## Text shortcuts
`cmd + d`  =  new Excalidraw sketch (inline embed)
`cmd + shift + c` =  add callout
`cmd + ;`  =  new property
`cmd + k`  =  add link
`cmd + shift + v`  =  paste without formatting
## Window management
`cmd + [`  =  split down
`cmd + ]`  =  split right
`cmd + l`  =  open workspace type
`cmd + shift + l`  =  manage workspaces
`cmd + shift + m`  =  zen mode
`cmd + g`  =  open graph view
## File management
`cmd + shift + r`  =  rename file
`cmd + shift + e`  =  export as PDF
`cmd + shift + d`  =  open daily note
`cmd + option + shift + d`  =  open tomorrow's daily note
