### Important
`right cmd = super` – Global Vorssaint-enabled super key

## Global
`super + ;` = switch appearance using Umbra
`super + k` = keep awake using Vorssaint
`super + space` = Claude quick open

## Text replacements
`pyblock` = an Obsidian Python code block.
## Safari
`super + 1` = Personal profile
`super + 2` = Uni profile
`super + 3` = Work profile
`super + 4` = Dev profile
## Preview
`super + '` = Toggle dark view of PDF
